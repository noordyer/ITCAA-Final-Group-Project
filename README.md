This was a group project in which we designed and implemented a smart irrigation system using an Arduino Uno R3 and Raspberry Pi 3B+ to automate watering based on real-time environmental conditions. The system used three soil moisture sensors, three sprinkler zones, servo-based pump indication, LCD status feedback, intrusion detection, timed watering cycles and a maintenance alert after repeated use. We also applied multithreading and multitasking principles so that sensing, control, alerts and monitoring could run responsively at the same time. The project combined hardware integration, embedded programming, sensor logic and system testing to solve a practical water-efficiency problem in agriculture.

This project is highly relevant to my portfolio because it demonstrates my ability to work across both hardware and software in a real-world embedded systems context. It strengthened my skills in microcontrollers, sensor integration, C/C++ development, multithreading, system design, testing and problem-solving under practical constraints, such as power stability and sensor calibration. It also shows that I can contribute effectively in a team while building solutions that are technically functional and socially meaningful. Overall, the project reflects my interest in intelligent systems, automation and applying computing to solve real-world challenges.
